# 全球人形机器人挑战赛 2026 — 参赛选手作品提交规范

## 1. 概述

评测系统采用**双容器隔离架构**，选手提交 **infer 容器**，实现策略推理。

| 容器 | 职责 | 谁提供 |
|------|------|--------|
| sim-eval | Isaac Sim 仿真、观测采集、断言评测、结果落盘 | 主办方 |
| sim-infer | 策略模型加载、推理、policy reset | **选手** |

两个容器通过 **WebSocket** 通信（msgpack 序列化 + lz4 压缩）：
- control 通道 (8765)：start / episode_end / stop
- stream 通道 (8766)：observation / action

---

## 2. 系统架构

```
┌─── sim-eval 容器 (主办方) ────────────┐  WebSocket   ┌─── sim-infer 容器 (选手) ──┐
│                                       │              │                            │
│  Isaac Sim 仿真                       │  ── obs ──→  │  PolicyAdapter              │
│  robot.get_observation()              │              │   ├─ load()     加载模型    │
│  robot.send_action()                  │  ←─ action ── │   ├─ predict()  推理动作    │
│                                       │              │   ├─ reset()    重置状态    │
│  Task1-4 Assertion 断言评测           │  ── ctrl ──→  │   └─ close()    释放资源    │
│  计分 + 结果落盘                      │              │                            │
└───────────────────────────────────────┘              └────────────────────────────┘
```

选手 infer 容器收到的是 **LeRobot 标准格式观测**（`observation.state` + `observation.images.*`），无需关心 Isaac Sim 内部细节。

## 3. 选手必须实现的接口

### 3.1 PolicyAdapter（必需）

选手需实现 `PolicyAdapter` 抽象类，包含 4 个方法：

```python
class PolicyAdapter(abc.ABC):

    @abc.abstractmethod
    def load(self, model_path: str, device: str, config: dict) -> None:
        """加载模型权重。config 包含 task、task_text 等运行时信息。"""

    @abc.abstractmethod
    def predict(self, observation: dict, context: InferenceContext) -> torch.Tensor:
        """根据观测推理一步动作，返回 1D tensor。"""

    @abc.abstractmethod
    def reset(self, reset_context: ResetContext | None = None) -> None:
        """episode 结束时重置策略内部状态（action queue、history 等）。"""

    @abc.abstractmethod
    def close(self) -> None:
        """释放适配器持有的资源。"""
```

### 3.2 上下文数据类型

```python
@dataclass
class InferenceContext:
    task: str          # 任务名，如 "task4"
    task_text: str     # 任务描述，如 "packing box"
    episode_id: int    # 当前 episode 编号
    step: int          # 当前 step 编号
    timestamp: float   # 观测采样时间戳

@dataclass
class ResetContext:
    episode_id: int
    status: str = "reset"   # success / failed / timeout / error
    reason: str = ""        # 结束原因说明
    metrics: dict = {}      # 该 episode 的指标
    step: int = 0
```

### 3.3 默认实现参考

赛事提供 `LeRobotPolicyAdapter`，自动处理 obs tensor 化、图像归一化、维度裁剪等。选手可直接使用或继承。

```python
from src.lerobot.sim_eval.policy_adapter import PolicyAdapter, LeRobotPolicyAdapter

class MyAdapter(LeRobotPolicyAdapter):
    # 继承默认实现，重写 predict() 即可
    def predict(self, observation, context):
        # ... 自定义预处理 + 推理
        return action
```

## 4. 数据维度规范

### 4.1 Observation

观测通过 WebSocket 以 **LeRobot 标准 key** 传递：

```python
observation = {
    "observation.state": torch.Tensor,   # shape (20,) — 关节位置 + 夹爪
    "observation.images.head_left":  torch.Tensor,  # (3, 480, 640) float32，RGB
    "observation.images.head_right": torch.Tensor,
    "observation.images.wrist_left":  torch.Tensor,
    "observation.images.wrist_right": torch.Tensor,
    # task4 模型可能接收 18 维 state（无夹爪），adapter 会自动裁剪
}
```

**observation.state 结构（20 维）：**

| 索引 | 含义 | 关节名 |
|------|------|--------|
| 0–6 | 左臂 7 关节 | L_shoulder_pitch/roll/yaw, L_elbow_roll/yaw, L_wrist_pitch/roll |
| 7–13 | 右臂 7 关节 | R_shoulder_pitch/roll/yaw, R_elbow_roll/yaw, R_wrist_pitch/roll |
| 14–17 | 夹爪手指 | L_finger1/2, R_finger1/2 |
| 18 | 左夹爪控制 | left_gripper |
| 19 | 右夹爪控制 | right_gripper |

### 4.2 Action

`predict()` 返回的 action 为 **一维动作向量**，维度与模型 `config.json` 中 `output_features.action.shape` 一致（通常 18 或 20 维）。

**要求：**
- 支持 `torch.Tensor`、`np.ndarray` 或 `list[float]`
- shape 为 `(20,)`；task4 也可返回 `(18,)`，系统会自动在末尾补 2 个夹爪控制量
- 无 batch 维度
- adapter 已自动 squeeze，无需手动处理

## 6. 接口自检清单

| 接口 | 必要性 | 标准 |
|------|--------|------|
| `adapter.load(path, device, config)` | ✅ | 成功加载模型权重，policy 进入 eval 模式 |
| `adapter.predict(obs, ctx)` | ✅ | 输入合法 obs，返回正确维度的 action |
| `adapter.reset(ctx)` | ✅ | 调用无异常，不影响后续推理 |
| `adapter.close()` | ✅ | 释放 GPU 显存 |

## 7. 常见问题

**Q: 可以用非 LeRobot 的模型吗？**
可以。继承 `PolicyAdapter`，实现 `load / predict / reset / close` 即可。在 `infer.yaml` 中用 `adapter_class` 指定自定义类。

**Q: task4 的 observation.state 是 18 维？**
task4 模型训练时不含夹爪控制，所以 state 是 18 维。`LeRobotPolicyAdapter` 会从 `config.json` 自动读取期望维度并裁剪，选手无需处理。

**Q: 图像是什么格式？**
4 路 RGB 相机，shape `(3, 480, 640)`，float32，值域 [0, 1]。

**Q: 可以引入额外依赖吗？**
可以。在 Dockerfile 或 pyproject.toml 中声明即可。
